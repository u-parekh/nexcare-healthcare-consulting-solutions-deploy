# NEXCARE — Healthcare Consulting Website
(ReactJS |JavaScript | Python | FastAPI | MongoDB | Resend | Vercel | Render)
▸Developed and deployed a production-ready healthcare consulting website for a real client, delivering a modern, responsive, and user-friendly experience across desktop and mobile devices.
▸Built the frontend using React.js with reusable components, responsive layouts, and optimized UI for improved accessibility and performance.
▸Developed a FastAPI based backend to manage contact inquiries, API requests with efficient RESTful endpoints.
▸Integrated MongoDB for secure storage and management of customer enquiries submitted through the website.
▸Integrated Resend for email delivery, enabling contact form notifications and email communication between the website and the client.
▸Deployed and configured the frontend on Vercel and the backend on Render, enabling independent deployment, environment variable management, and reliable communication between application services.
